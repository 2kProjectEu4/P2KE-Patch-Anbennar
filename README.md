# P2KE Patch - Anbennar

This repository contains the Anbennar compatibility patch for Proper 2K UI Enhanced. It updates and aligns Anbennar-specific interface assets so the UI remains usable and consistent when both mods are enabled together.

## Requirements

- Europa Universalis IV `1.37.*.*`
- Proper 2K UI Enhanced
- Anbennar: A Fantasy Total Conversion

## Load Order

Use this exact order:

1. Proper 2K UI Enhanced
2. Anbennar: A Fantasy Total Conversion
3. P2KE Patch - Anbennar

## What This Patch Covers

This patch is focused on graphics and interface compatibility. The repository includes Anbennar-related GUI and GFX overrides, event picture assets, and government mechanics interface files that adapt the P2KE UI to Anbennar content.

## Installation

If you are using the Steam Workshop version, subscribe to the required mods and enable them in the load order above.

If you are installing manually, place this mod in your Europa Universalis IV mod directory and make sure the descriptor file is paired with the mod content.
